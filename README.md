# Vicky FPS

A small Unity FPS starter with:

- First-person movement, sprinting, jumping, and gravity
- Mouse look with pitch clamp
- Hitscan weapon with ammo and reload
- Damageable targets
- Simple on-screen HUD
- Editor menu to generate a starter scene

## How to Use

1. Open this folder in Unity.
2. In Unity, choose `Tools > Vicky FPS > Create Starter Scene`.
3. Open `Assets/Scenes/StarterArena.unity`.
4. Press Play.

## Controls

- `WASD`: Move
- `Mouse`: Look
- `Left Mouse`: Shoot
- `R`: Reload
- `Shift`: Sprint
- `Space`: Jump
- `Escape`: Unlock mouse
